1. Introducción
1.1 Descripción general

Esta aplicación web permite la gestión completa de las estancias formativas de los alumnos, facilitando la comunicación y el seguimiento entre alumnos, tutores de centro y tutores de empresa.

1.2 Objetivo del manual

El objetivo de este manual es explicar paso a paso cómo acceder y utilizar todas las funcionalidades de la aplicación según el rol del usuario.

1.3 Requisitos previos

Disponer de un navegador web (recomendado: Google Chrome).

Tener conexión a Internet.

Ser un usuario registrado en el sistema (alumno, tutor de centro, tutor de empresa o administrador).

2. Acceso a la plataforma
2.1 Login

Todos los usuarios acceden desde la misma pantalla de inicio de sesión.

Pasos:

Introducir el correo electrónico proporcionado por el centro.

Introducir la contraseña asignada.

Pulsar el botón Iniciar sesión.

2.2 Logout

El cierre de sesión es igual para todos los usuarios.

Pasos:

Pulsar el botón Cerrar sesión desde la aplicación.

La sesión se cerrará automáticamente y se volverá a la pantalla de login.

3. Vista Administrador

⚠️ El administrador tiene funciones limitadas de gestión.

3.1 Acceso

Iniciar sesión como administrador.

Se mostrará una vista con las opciones disponibles.

3.2 Funcionalidades disponibles
Crear entidades

Al pulsar el botón Crear, aparece un desplegable con las siguientes opciones:

Crear empresa

Rellenar los datos de la empresa.

Pulsar Crear empresa para guardarla.

Crear usuario

Rellenar todos los campos del formulario.

Seleccionar el tipo de usuario (alumno, tutor centro, tutor empresa, administrador).

Pulsar Crear usuario.

Crear competencias técnicas

Rellenar los campos requeridos.

Seleccionar el grado correspondiente.

Marcar los Resultados de Aprendizaje (RAs) necesarios.

Pulsar Guardar competencia.

Crear Resultados de Aprendizaje (RAs)

Rellenar los campos.

Seleccionar el grado.

Elegir la asignatura asociada.

Guardar el RA.

4. Vista Tutor de Centro
4.1 Acceso

Iniciar sesión como tutor de centro.

Se mostrará la pantalla principal con tres botones principales.

4.2 Información del alumno

Pulsar Info alumno.

Seleccionar el grado en el primer desplegable.

Seleccionar el alumno del grado.

Se mostrará la información general del alumno.

4.3 Funcionalidades disponibles
Ver calendario

Si el alumno tiene calendario:

El tutor puede ver y editar el calendario.

Si no tiene calendario:

Crear una estancia.

Asignar fechas, horarios y días laborales.

Guardar el horario.

Ver empresa

Si no hay empresa asignada:

Seleccionar una empresa de la lista.

Indicar fechas, horas y días.

Asignar la empresa.

Después:

Asignar un tutor de empresa desde el desplegable.

Ver seguimiento

Si no existen seguimientos:

Aparece un mensaje y opción para crear uno nuevo.

Crear seguimiento:

Rellenar los campos.

Guardar el seguimiento.

Gestión:

Editar o eliminar seguimientos existentes.

Ver notas

Ver notas del alumno.

Editar la nota de centro.

Calcular la nota final del alumno.

Cuaderno

Crear entregas por grado.

Ver entregas de los alumnos.

Filtrar por grado.

Ver cuadernos subidos en una nueva pestaña.

Evaluar cuadernos y guardar la nota.

5. Vista Tutor de Empresa
5.1 Acceso

Iniciar sesión como tutor de empresa.

Se mostrará la pantalla principal.

5.2 Información del alumno

Seleccionar grado y alumno.

Visualizar información general del alumno.

5.3 Funcionalidades disponibles
Ver calendario

Si no hay calendario:

Contactar con el tutor de centro.

Si hay calendario:

Solo visualización.

Ver empresa

Si no hay empresa asignada:

Aparece mensaje para contactar con tutor de centro.

Si hay empresa:

Se muestra la información (solo lectura).

Seguimiento

No puede ver ni editar seguimientos.

Poner notas

Evaluar competencias técnicas:

Seleccionar competencia.

Asignar nota del 1 al 4.

Posibilidad de eliminar.

Evaluar competencias transversales:

Asignar nota del 1 al 4.

6. Vista Alumno
6.1 Acceso

Iniciar sesión como alumno.

Se mostrará la pantalla principal.

6.2 Funcionalidades disponibles
Información del alumno

Visualizar información personal.

Ver calendario

Si no hay calendario:

Contactar con tutor de centro.

Si existe:

Visualización del calendario.

Ver empresa

Si no tiene empresa:

Aparece mensaje informativo.

Si tiene empresa:

Se muestra la empresa y tutor asignados.

Ver seguimiento

Si no hay seguimientos:

Aparece mensaje informativo.

Si hay:

Se muestran los seguimientos.

Ver notas

Visualizar notas.

Calcular nota final.

Cuaderno

Subir cuaderno en PDF:

Si hay entrega pendiente, se habilita el botón.

Seleccionar archivo PDF.

Pulsar Subir.

Si no hay entregas:

Aparece mensaje informativo.
